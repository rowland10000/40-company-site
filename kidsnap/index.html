免費工具

KIDSNAP

一張臉，把長大串起來。把同一個孩子不同時期的照片丟進來，它會自動找出他、把臉對齊到同一個位置，做成一段「看著長大」的短片。

macOS · 免費 · 照片不會上傳

所有的偵測、辨識、對齊、調色、做影片都在你自己的電腦裡完成。沒有帳號、沒有雲端、沒有費用。關掉網路也能用——只有第一次安裝需要連網。

下載 KIDSNAP（約 70MB）

安裝：雙擊一個檔案

  1. 解壓縮 KIDSNAP_release.zip，得到一個 KIDSNAP 資料夾，放哪裡都可以
  2. 打開資料夾，雙擊「啟動 KIDSNAP.command」
  3. 第一次會跳出黑色視窗自動安裝，約 3～5 分鐘，裝完自動啟動
  4. 瀏覽器會自己打開 KIDSNAP 的畫面。之後每次都是雙擊同一個檔案，一分鐘內開啟
電腦要有 Python 3.9～3.12。沒有的話，雙擊時會提示你去 python.org 安裝（一路按「繼續」就好），裝完再雙擊一次。

如果 macOS 說「無法打開，因為來自未識別的開發者」：在「啟動 KIDSNAP.command」上按右鍵 →「打開」→ 再按一次「打開」。只有第一次需要。

四個步驟

① 選主角

先選輸出尺寸（1:1 貼文、9:16 限動、16:9 電視、4:5 直式），再上傳一張主角的清晰獨照。右邊會自動框出偵測到的臉，綠框就是目標人物；合照裡有好幾張臉就點一下要的那張。按「設定為目標人物」。

② 丟照片

把主角從小到大的照片一次全選進來（一次最多 150 張），按「開始對齊」。

它會依拍攝日期由舊到新排序，偵測每張照片裡的臉，沿著時間接力認出主角——用前後年代剛認出的臉當線索，所以嬰兒期的照片也串得起來——再旋轉、縮放、裁切到同一個位置，最後統一亮度與膚色。

認不出或偵測不到臉的照片會被排到最後並標明原因，不會進到影片裡。合照中兩張臉太像時它寧可略過也不亂選。

③ 排順序

對齊好的照片以卡片排出來，預設照拍攝日期排好，通常不用動。想改就直接拖拉。

接著選速度（每秒 6／12／24 張）、格式（MP4 或 GIF）與儲存位置，按「建立動圖」。150 張用預設速度大約 12 秒。

④ 加風格（可略過）

套上相框、色塊海報、弧形大字或塗鴉描邊。同一個風格再點一次會換一組配色與排版。可以放上今天日期或生日——選生日時主標會自動變成 Happy Birthday。

常見問題

狀況怎麼辦
明明是同一個孩子，卻說「未匹配目標人物」通常是臉太小、側臉或光線太差。把目標人物換成年代比較接近那張的獨照，接力辨認會更容易串起來。
合照裡選到別人兄弟姊妹長得像時可能發生。把那張裁成獨照再處理。
照片順序不對順序依照片裡的拍攝時間。經 LINE、Messenger 轉傳過的照片常常沒有這個資訊，會被排到最後，在第 ③ 步拖拉調整。
影片太大或太長選 MP4 不要選 GIF（GIF 大 4～5 倍）；照片多時把速度調「快」。
照片會不會被上傳不會。全部在你的電腦裡完成，不連任何雲端服務。
